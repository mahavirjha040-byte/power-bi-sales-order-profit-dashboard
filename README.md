Power BI Sales, Orders & Profit Dashboard

Project Overview

This project presents an interactive Power BI dashboard designed to analyze sales performance, order volume, profitability, and geographical trends.

Key Features

KPI Cards: Total Sales, Total Orders, and Total Profit.

Country-wise Sales: Identifies the countries contributing the highest sales.

Sales Trend Analysis: Tracks sales performance over time.

Region-wise Analysis: Explores the relationship between order volume and sales.

City-wise Sales: Compares sales contributions across cities.

Interactive Filters: Allows users to explore data by month and year.

Tools Used

Microsoft Power BI

DAX

Data Visualization

Business Intelligence

Dashboard Preview



Project Objective

To transform sales data into an interactive visual report that helps users explore business performance and identify meaningful trends.
